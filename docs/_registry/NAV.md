| Código | Módulo | Cuándo usar |
| --- | --- | --- |
| NAV-001 | [Nav bar](NAV/NAV-001-nav-bar.md) | Barra de navegación principal fija en la parte superior de cada página del sitio. Proporciona acceso global a las secciones principales y un CTA de conversión. |
| NAV-002 | [Footer completo](NAV/NAV-002-footer-completo.md) | Pie de página completo para sitios con múltiples secciones que requieren navegación secundaria, datos de contacto y vínculos legales. |
